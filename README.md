# Lab 3 : Construire un écran d’accueil défilant avec ScrollView

## Partie 1 : Affichage avec View

Dans cette première partie, nous avons utilisé le composant View pour afficher un texte de bienvenue dans l'écran WelcomeScreen.

Cependant, le texte est trop long et dépasse la taille de l'écran. Le composant View ne permet pas de faire défiler le contenu, donc une partie du texte reste invisible.

## Partie 2 : Utilisation de ScrollView

Dans cette deuxième partie, nous avons remplacé le composant View par ScrollView.

Le composant ScrollView permet de faire défiler le contenu verticalement. Ainsi, l'utilisateur peut monter et descendre pour lire l'intégralité du texte de bienvenue.

Capture d'écran 2 : Affichage avec ScrollView

## Partie 3 : Utilisation de indicatorStyle="white"

Dans cette troisième partie, nous avons ajouté la propriété indicatorStyle="white" au composant ScrollView.

Cette propriété permet de définir la couleur de l'indicateur de défilement en blanc. Sur un fond sombre, cela améliore la visibilité de la barre de défilement.
